Explanations

Click an action above to fetch Jolokia JSON. This panel explains the most common keys and how to interpret the returned data.

Common endpoints
  • /jolokia/list: lists JMX domains → MBeans → attributes and operations. Use it to discover available MBeans.
  • /jolokia/read/...: reads attributes of a specific MBean. Returns attribute names and values.
  • /jolokia/exec/...: invokes an operation on an MBean (use with caution).
JSON keys you'll see
  • request: the original Jolokia request metadata (type, mbean, attribute).
  • value: main payload — for list it's nested domains; for read it's attribute map.
  • timestamp: server-side event time (epoch seconds).
  • status: numeric: 200 = OK; non-200 indicates error.
  • error: error message when status != 200.
How to read MBean attribute data
  1. Find the domain (left-side key) in the list result, expand to MBean names.
  2. Attributes contain type/description in the list result; use read to get runtime values.
  3. Metric-style attributes (e.g., HeapMemoryUsage) are objects with subfields like init, used, committed, max (bytes).
Tip: Use /jolokia/read/java.lang:type=Runtime to see JVM uptime, startTime, and inputArguments.
